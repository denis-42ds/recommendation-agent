# ADR-008: Scope freeze перед сдачей MVP

- **Дата:** 27.11.2026
- **Статус:** ACCEPTED

## Контекст

До сдачи около 23 часов, ожидаемое доступное время разработки — 4–5 часов. Подготовлены baseline/backtest, каталог и граф совместных покупок. Последний подтверждённый прогон автоматических проверок: 34 теста прошли, Ruff и `git diff --check` без ошибок.

При этом Recommendation Engine и демонстрационный end-to-end сценарий ещё не подтверждены как готовые. Дальнейшая диагностика качества сопоставления каталога может поглотить время, не обеспечив демонстрируемый продукт.

## Рассмотренные варианты

1. Продолжить исследование каталога и расхождений co-purchase до полной уверенности.
2. Реализовать все три сценария Cross-sell, Up-sell, Renewal одновременно.
3. Зафиксировать текущие артефакты и реализовать минимальный Cross-sell end-to-end.

## Решение

Выбран вариант 3.

- Зафиксировать текущие результаты подготовки данных.
- Не менять правила catalog matching без конкретной диагностики.
- Не блокировать движок из-за неполного Match Rate.
- Реализовать Cross-sell на co-purchase с popularity fallback.
- Обеспечить фильтрацию ранее купленных товаров и проверку принадлежности каталогу.
- B2B и B2C обрабатывать раздельно; B2C не использовать отрасль и корпоративный профиль.
- Объяснения формировать из фактов, без LLM.
- Сначала обеспечить локальный end-to-end, затем тратить время на Docker/Cloud Run.

## Последствия

Положительные:
- максимизируется шанс получить работающую демонстрацию;
- используется уже подготовленный граф и каталог;
- сокращается число новых компонентов.

Ограничения:
- часть товаров не попадёт в рекомендации из-за неполного сопоставления каталога;
- Up-sell и Renewal остаются за пределами текущей реализации;
- co-purchase означает статистическую связь покупок, а не техническую совместимость;
- публичный деплой может быть отложен, если локальная версия нестабильна.

## Критерии пересмотра

Пересматривать scope только если Cross-sell end-to-end завершён и остаётся подтверждённый запас времени либо если выбранный подход не позволяет получить ни одной корректной рекомендации для демонстрационных клиентов.
