## 3. Управление зависимостями

В `pyproject.toml` используются минимальные версии зависимостей, а не точная фиксация всех версий.

Это означает, что:
- локальное окружение разработчика может отличаться от Docker-окружения;
- транзитивные зависимости могут обновляться;
- приведённый список основных библиотек не является полным перечнем всех установленных пакетов.

## 4. Получение фактического отчёта

Для формирования перечня лицензий фактически установленного окружения:

```bash
python -m pip install pip-licenses
pip-licenses --format=markdown
```

Для сохранения результата:

```bash
pip-licenses --format=markdown > docs/THIRD_PARTY_LICENSES.md
```

После выполнения команды следует проверить:
1. наличие всех прямых зависимостей;
2. наличие транзитивных зависимостей;
3. корректность названий лицензий;
4. пакеты с неизвестной или нестандартной лицензией;
5. соответствие окружения тому, из которого собирается Docker-образ.

## 5. Статус аудита

- Основные прямые зависимости перечислены.
- Предварительные лицензии основных компонентов указаны.
- Полный список транзитивных зависимостей не подтверждён.
- Лицензии пакетов внутри опубликованного Docker-образа отдельно не проверены.
