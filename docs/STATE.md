## 4. Backtest — зафиксированный протокол

- Train: `order_week <= 2026-08-31`.
- Test: `order_week >= 2026-09-07`.
- Цель: новые `item_id` в Test, отсутствовавшие в Train.
- Cohort A: клиенты с покупками в Train и минимум одним новым товаром в Test.
- Cohort B: подмножество A с ровно одним уникальным товаром в Train.
- Precision@3: делитель всегда 3.
- B2B и B2C оцениваются раздельно.
- Для baseline Popularity популярность — число уникальных клиентов, купивших товар в Train.
- Для Co-purchase считаются Train baskets; идентичность корзины — `(order_id, order_week)`.

Официальные результаты организаторов:
- Popularity P@3: A ALL 5.2%, B2B 3.6%, B2C 19.4%; B ALL 7.0%, B2B 5.1%, B2C 19.2%; Fill Rate 100%.
- Co-purchase P@3: A ALL 4.8%, B2B 3.9%, B2C 13.0%; B ALL 5.1%, B2B 3.8%, B2C 12.8%; Fill Rate A 89%, B 82%.

Локальные результаты пользователя:
- Размеры когорт совпали с официальными.
- Popularity совпадает с официальными с учётом округления.
- По Co-purchase есть расхождения; они требуют анализа, но сами по себе не доказывают ошибку реализации.

## 5. Принятые решения

- **DEC-001:** MVP-first, минимальная архитектура.
- **DEC-002:** Streamlit для UI.
- **DEC-003:** JSON/CSV для данных MVP.
- **DEC-004:** Детерминированные правила и scoring; базовая логика без LLM.
- **DEC-005:** LLM, если появится, только переформулирует объяснение по фактам.
- **DEC-006:** Сначала локальная версия, затем Docker и Cloud Run.
- **DEC-007:** Cloud Run — основной публичный стенд; ngrok — резерв.
- **DEC-008:** Зафиксировать scope freeze: Cross-sell first; не расширять исследование каталога, пока оно не блокирует корректную рекомендацию.

## 6. Ограничения и риски

- B2C: не использовать `industry` и корпоративный профиль.
- Не выдавать совместную покупку за доказательство совместимости.
- Не рекомендовать товары вне каталога.
- Не использовать цены/наличие без подтверждённого актуального источника.
- Исторических snapshots каталога и профилей нет; текущие данные каталога нельзя без оговорок использовать как историческое состояние в backtest.
- Исходный датасет не публиковать.
- Не заявлять рост конверсии или выручки без эксперимента.
