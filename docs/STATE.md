## 1. Цель

Создать за 48-часовой хакатон работающий и демонстрируемый MVP Recommendation Agent для личного кабинета B2B интернет-магазина.

Приоритеты:
1. Рабочий end-to-end сценарий.
2. Локальный запуск.
3. Публичный HTTPS-доступ к демо.
4. Объяснимые и проверяемые рекомендации.
5. Минимум инфраструктуры и зависимостей.
